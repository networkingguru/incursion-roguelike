# Spelling

## all-prose-uses-american-spelling
ALL prose in this project MUST use American spelling: game text and Descs in `lib/*.irh`, in-game help, player-facing strings in `src/`, `README.md`, `docs/`, bead titles, descriptions and notes, commit messages, drafts put to Brian for approval, and every agent reply. Write color, favor, honor, armor, gray, behavior, defense, offense, center, traveled, jewelry, recognize, realize, practice (verb). Code identifiers (`FAVOUR_CHART`, `VOICE_COLOUR`, `SL_ARMOUR`, `gainFavour`) and resource names a script or save looks up by string are NOT prose: do NOT rename them under this rule. A verbatim quote stays verbatim. Existing British text is converted under bead inc-qxf9.
Why: one spelling standard for the whole project, and the owner chose American.
History: new rule, no prior narrative to archive. Bead inc-ur36.
