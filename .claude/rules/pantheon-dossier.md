# Pantheon dossier sessions

## pantheon-dossier-start-from-the-brief
A session that designs or continues a pantheon (inc-pu6v) god dossier MUST read `~/Scripts/Incursion-inc-pu6v/dossier-brief/README.md` first and load only the files it names. It MUST NOT run `bd show inc-pu6v`, or `bd show` on a designed god's bead, to orient (100–540 KB each). It MUST NOT read `src/` or `lib/` in the shared checkout, because master holds the old religion engine. Open a bead note or a `docs/GOD-CONTRACT.md` row only for a fact the brief lacks. When a god has a ruling ledger at `~/Scripts/Incursion-inc-pu6v/dossier-brief/ledgers/<bead>.md` (built by `tools/fidelity/`, see its README), read that ledger BEFORE the god's summary brief `gods/<bead>.md`; where they disagree, the ledger wins, and a ruling's Status and Fidelity lines say whether it is in force and whether Brian approved it. The brief is git-ignored and dies with the epic worktree. When inc-pu6v lands, delete this entry and run `bd forget pantheon-dossier-session-start`.
Why: the raw beads cost about 530 KB and carry superseded claims that contradict the branch code.
History: new rule, no prior narrative to archive. Beads inc-d6z3, inc-h5d5 (ledger first: Maeve's summary brief dropped R108/R109).
