# Incursion — ROG Ally X controls

Steam Input layout, generated from the live config
(`controller_rog_ally_incursion.vdf`). Movement uses the **numpad** keys.

## Notes

- **Press / hold / double-tap** are three separate bindings on the same button.
  Hold is ~1/3 second.
- **A and B have press and hold swapped** from the obvious arrangement: a press
  sends `y`/`n`, a hold sends Enter/Esc. On the map a press of A opens the YUse
  menu and a press of B opens the Name prompt — those are real commands, not
  misfires. Backing out of a menu is a **hold** of B.
- **Movement spans two controls.** Steam Input cannot emit more than four
  directions from one stick or d-pad — verified against every d-pad `layout`
  mode and every source mode. Cardinals are on the d-pad, diagonals on the right
  stick (its regions rotated 45°, so pushing toward a corner gives that corner).
- Anything unbound — page-by-letter item lists and the rest of the command set —
  is reachable via the **on-screen keyboard** on M1.
- `W` (wizmode) is deliberately unbound.
