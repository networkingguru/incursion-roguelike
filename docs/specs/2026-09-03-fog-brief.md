## ITEM A — fog TERRAIN must fill `FogCol[]`

**Defect.** `ScanFog` (`src/Light.cpp:469-480`) walks `m->Fields` and takes only
`FI_FOG`. The fog terrains in `lib/dungeon.irh` spawn no field, so a hand-placed
fog bank is invisible to the light map. Only a cast cloud tints light.

**Change, one file, `src/Light.cpp`.** Inside `ScanFog`, after the `memset` and
**before** the field loop, sweep the map. For each cell whose terrain satisfies

    tt->HasFlag(TF_OBSCURE)
      && (tt->Material == MAT_EMPTYNESS || tt->Material == MAT_FORCE)

set `FogCol[idx] = (GLYPH_FORE_VALUE(tt->Image) & COLOUR_MASK) + 1`.

Terrain first, fields second, so a cast cloud overwrites terrain on a shared
cell. Update `ScanFog`'s comment to say it reads both.

**Do NOT touch** `CellFilter`, `FilterMark`, `ScanTerrain`, or any knob in
`inc/Light.h`. They already read `FogCol` and do not care what filled it.

**Why that predicate and not `TF_OBSCURE` alone.** Seven terrains carry
`TF_OBSCURE`. Four are fog: stinking cloud, fog, solid fog bank, acid fog
(`lib/dungeon.irh:999,1021,1037,1048`). `Old Webbing` and `Webbing` are
`MAT_WEBBING` and Brian ruled them out. `storm of sleet` (`:1356`) is `MAT_ICE`
and already filters through the ice branch of `CellFilter`; claiming it as fog
as well would dim it twice. The material test excludes all three.
`MAT_FORCE` is in the predicate solely for `solid fog bank`.

**Oracle.** Add `tools/keys/light-fogterrain.keys` beside the existing
`light-fog.keys`, built the same way but PLACING fog terrain with the wizard
instead of casting Stinking Cloud. Read `tools/keys/light-fog.keys`'s header
first: it records the three traps that bit the earlier scripts. You must
discover the wizard terrain letter for a fog terrain yourself by running the
harness and reading the "Which terrain type?" prompt — do not guess it, and do
not assume it is stable across the list.

Then extend `tools/check_light_fog.sh` to run BOTH subjects and pass only if
both do. Keep the existing cast case working unchanged.

**Acceptance.** Do not hard-code the digit `1`: the terrain called `fog` is grey
where Stinking Cloud is green, so its tint differs from the cast case. Require
instead, on the measured cell, that the fogged reading is strictly LESS than the
clear reading and strictly GREATER than zero — dimmed, not stopped.

**Red-green, both directions, and report the output of each:**
1. Remove your terrain sweep. The placed-fog case must FAIL with the two
   readings equal.
2. Restore it. Both cases must pass.
