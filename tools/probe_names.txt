# tools/probe_names.txt -- every INCURSION_* environment name the code reads.
# Format: NAME<TAB>OWNER<TAB>MEANING, one row per name, sorted by NAME in byte order.
# OWNER is the bead id that added the name, or `pre-registry` for a name that
# existed before this file. MEANING is one short line; a pre-registry row uses `-`.
# Rule: a new name gets a row here, in sorted place. Two branches that add the
# same name touch the same neighbourhood and git conflicts. tools/check_probe_names.py
# fails on an unregistered name, a stale row, a second row, an unsorted row or a bad row.
