iNCURSION for macOS
===================

This is Julian Mensch's Incursion, ported to run natively on the Mac.

Incursion.txt, beside this file, is the original project's readme. Read it for
the game itself — but note that it predates this port, and the source and issue
links in it point at a Bitbucket repository that is no longer where the work
happens. Use the addresses below instead.


Where your files live
---------------------

    ~/Library/Application Support/Incursion/

Saves, options and logs are all in there. Deleting the app does not remove them;
delete that folder too if you want a clean sweep.

They are deliberately kept outside the app. An app bundle that writes inside
itself breaks its own code signature, and macOS then refuses to launch it with
"the app has been modified or damaged".

Inside that folder you will find "mod" and "fonts" as symbolic links pointing
back into the app. That is intentional: the game keeps one directory for both
reading and writing, so the writable copy is the real one and the read-only game
data is linked in.


Reading a character without playing
-----------------------------------

This port can print a full character report from a save file, straight to a
Terminal window, without starting the game. No window opens and nothing is
written -- the save is opened for reading only.

    /Applications/Incursion.app/Contents/MacOS/Incursion -dump \
        ~/Library/Application\ Support/Incursion/save/YourCharacter.sav

You get current and maximum hit points, position and depth, every equipped
slot, every effect on the character, the whole inventory including what is
inside containers, what is on the floor underneath, and the complete character
sheet with feats, skills and saving throws.

Add "> character.txt" to the end to keep it as a file.

The report is produced by the game's own character-sheet code reading the real
save, so it always agrees with what the game itself believes.


Requirements
------------

macOS on Apple Silicon. Intel and Linux builds are planned.


Reporting a problem
-------------------

For anything about the Mac build — it will not launch, it crashes, saves do not
load — report it here:

    https://github.com/networkingguru/incursion-roguelike/issues

Please say which macOS version and which Mac you are on, and paste any output.
If a crash produced a report, macOS keeps it in
~/Library/Logs/DiagnosticReports and that file is the single most useful thing
you can attach.

For questions about the game's rules or content rather than this port, the
parent project is:

    https://github.com/rmtew/incursion-roguelike
